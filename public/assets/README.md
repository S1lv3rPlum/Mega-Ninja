# Mega-Ninja asset checklist

Placeholders are generated by `make_placeholders.py`. To use real art, drop a PNG
with the **same filename and size** over the placeholder (pixel art, no smoothing).

| File | Size | Used for |
|------|------|----------|
| tilesets/tiles.png | 64x16 (4 tiles of 16x16) | grass, path, water, tree |
| maps/town.json | 30x20 tiles | world map (edit in Tiled) |
| sprites/player.png | 16x16 | Mega-Ninja on the map |
| sprites/npc.png | 16x16 | townsperson |
| sprites/enemy-ninja.png, enemy-scout.png | 16x16 | enemies on the map |
| sprites/hero-portrait.png | 64x64 | party/menu portrait |
| sprites/enemy-ninja-battle.png, enemy-scout-battle.png, boss-battle.png | 64x64 | battle screen |
| items/potion, shuriken, key, coin, scroll .png | 16x16 | inventory icons |
| ui/title-logo.png | 224x56 | title screen logo |
| ui/title-bg.png | 320x240 | title screen background |
| ui/dialogue-box.png | 304x56 | NPC dialogue box |
| ui/button.png | 96x24 | menu buttons |
| ui/hp-frame.png, hp-fill.png | 64x8 / 62x6 | health bar |
| ui/battle-bg.png | 320x240 | battle backdrop |
| ui/icon.png | 64x64 | app icon / favicon |

Game screen is 320x240 (20x15 tiles) and scales up with crisp pixels.
