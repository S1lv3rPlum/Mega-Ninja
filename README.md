# Mega-Ninja

A top-down 2D RPG that runs in the browser. Built with Phaser 3 + Vite.

## Run
    npm install
    npm run dev

## Controls
Arrow keys / WASD to move. P to save (stored in this browser).

## Build for hosting
    npm run build     # outputs dist/ (static files)

Art placeholders: see public/assets/README.md
